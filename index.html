Projects

Tiny Object Detection

Feature selection under 60 px

A feature pyramid network paired with a CNN to select features for objects smaller than 60 pixels in area. A learned gate decides which layer to use, conditioned on the difference between the source and the target and on the average variance of the convolution.

FPNCNN Domain shiftObject detection

ViToNet

Real-time video captioning

Integrated the Titans memory module with LLaMA-3 to generate context-aware captions for live video, grounded in YOLO object detections so the narration keeps track of what has already happened on screen.

LLaMA-3Titans memory YOLOMultimodal

Honeybee Translator

Simulation design & AI integration

YOLOv2 and DeepSORT detect honeybee waggle dances, and an LLM renders them into human language. A simulation then converts that language back into a waggle dance, measuring how much information survives the round trip.
